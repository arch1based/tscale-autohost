# T-Scale AUTO HOST

ICS — ΚΑΡΑΦΥΛΛΗΣ ΣΥΣΤΗΜΑΤΑ ΠΛΗΡΟΦΟΡΙΚΗΣ · Θεσσαλονίκη · έκδοση 1.0 · Αύγουστος 2026

Windows daemon με γραφικό περιβάλλον που παίρνει το αρχείο εξαγωγής του ERP
και ενημερώνει τους ζυγούς T-Scale.

## Εκτέλεση
```
python autohost.py
```
Για .exe: τρέξε `build.bat` (φτιάχνει `dist\AutoHost.exe`, δεν χρειάζεται Python στο PC του πελάτη).

## Βήματα
0. **Αρχείο ERP → host1/host2** — διαλέγεις το αρχείο και τον φάκελο εξόδου. Μόλις το αρχείο
   αλλάξει, δημιουργούνται `host1.<κατάληξη>` και `host2.<κατάληξη>` και ξεκινά η ροή.
1. **Πρώτο βήμα (μετατροπή)** — on/off. Οι κανόνες φαίνονται και αλλάζουν σε απλό κείμενο:
   - `INPUTFIL=` / `OUTPUTFL=` (δέχονται `<HOST1>` και `<OUT1>`)
   - `CNV2WIN` (cp737 → cp1253), `CNV2DOS`, `UPPERCASE`
   - `SKIPLINE=n`, `PADLINE=n`
   - `DESCRIPT=θέση  μήκος` — κρατά μόνο αυτό το κομμάτι της γραμμής
   - `IFEXISTn=θέση=[τιμή] THEN=[νέα τιμή]` — αν στη θέση υπάρχει η τιμή, την αντικαθιστά (π.χ. `5` -> `-1`)·
     `THEN=[DELETE]` πετάει τη γραμμή
   Προαιρετικά μπορείς να ορίσεις εξωτερικό .exe μετατροπής (τρέχει με το script ως παράμετρο).
2. **Παράμετροι product.csv** — on/off. Πίνακας ίδιος με του ICS: Περιγραφή / Για έξοδο /
   Από Θέση / Μήκος Πεδίου / Εξτρα περιγραφή. Διπλό κλικ σε γραμμή για επεξεργασία,
   Space για ✓. Κουμπί «Δοκιμή» δείχνει προεπισκόπηση 5 γραμμών πριν το τρέξεις κανονικά.
   Το αρχείο εξόδου **δεν χρειάζεται να υπάρχει** — διαλέγεις φάκελο και όνομα και
   δημιουργείται/αντικαθίσταται σε κάθε ενημέρωση. Κενό = `product.csv` δίπλα στο host.
   Το κουμπί **«Προφίλ: PLU»** φορτώνει έτοιμες τις θέσεις για το fixed-width `PLU.txt` του ERP.
3. **AutoProcess** — on/off. Διαλέγεις το exe, τρέχει για 120 δευτ. (ρυθμιζόμενο) και κλείνει.

Στο τέλος βγαίνει μήνυμα επιτυχίας· σε σφάλμα βγαίνει μήνυμα με το βήμα, την αιτία και τη
διαδρομή/γραμμή που φταίει, ενώ ό,τι γίνεται καταγράφεται στο log κάτω-κάτω.

Οι ρυθμίσεις αποθηκεύονται στο `%APPDATA%\\ICS\\TScaleAutoHost\\autohost_config.json`,
ώστε να μη χάνονται σε κάθε νέο build του exe. Παλιό config δίπλα στο exe μεταφέρεται αυτόματα.

## Εκκίνηση με τα Windows
Στην 1η καρτέλα υπάρχει το checkbox **«Εκκίνηση με τα Windows»**. Όταν το τσεκάρεις, γράφεται
στο `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` (χρήστης, δεν θέλει admin) με
παράμετρο `--tray`: στο boot ανοίγει **ελαχιστοποιημένο κάτω δεξιά** στην περιοχή ειδοποιήσεων
και ξεκινά μόνο του την παρακολούθηση. Διπλό κλικ στο εικονίδιο το ανοίγει· δεξί κλικ δίνει
«Άνοιγμα / Εκτέλεση τώρα / Έξοδος». Το X το κρύβει ξανά κάτω δεξιά όσο τρέχει η παρακολούθηση.

Χρειάζεται `pip install pystray Pillow` (τα εγκαθιστά μόνο του το `build.bat`). Χωρίς αυτά
δουλεύει κανονικά, απλώς ελαχιστοποιείται στη γραμμή εργασιών αντί για κάτω δεξιά.

## Ξαναφτιάχνοντας το exe
`build.bat` → κλείνει μόνο του το `AutoHost.exe` αν τρέχει, καθαρίζει τα παλιά `build/`,
`dist/`, `AutoHost.spec` και ξαναχτίζει από την αρχή. Αν δεις `PermissionError: dist\AutoHost.exe`,
τρέχει ακόμα κάπου το exe — κλείσ' το και από το εικονίδιο κάτω δεξιά.

## Αξιοπιστία σε αφύλακτη λειτουργία
- **Σφάλμα ενώ είναι κρυμμένο**: δεν ανοίγει modal παράθυρο (δεν θα φαινόταν και θα μπλόκαρε τη
  ροή) — βγαίνει ειδοποίηση κάτω δεξιά, το εικονίδιο γράφει «ΣΦΑΛΜΑ» και οι λεπτομέρειες
  εμφανίζονται μόλις ανοίξεις ξανά το παράθυρο.
- **Αρχείο log**: κάθε γραμμή γράφεται και σε ημερήσιο αρχείο στο
  `%APPDATA%\ICS\TScaleAutoHost\logs\`. Κρατιούνται 30 ημέρες. Κουμπί «Αρχείο log».
- **Ένα μόνο αντίγραφο**: αν το ανοίξεις ενώ τρέχει ήδη (π.χ. ξεκίνησε με τα Windows), σου το λέει
  και σε στέλνει στο εικονίδιο κάτω δεξιά — δεν τρέχουν δύο daemon ούτε ανοίγει δύο φορές το
  AutoProcess.
- **Backup**: μετά από κάθε επιτυχή εκτέλεση κρατιέται αντίγραφο όλων των αρχείων
  (αρχείο ERP, host1, host2, έξοδος Βήματος 1, product.csv) σε
  `<φάκελος εξόδου>\backup\ΗΗΗΗ-ΜΜ-ΗΗ_ΩΩΛΛΔΔ\`. Κρατιούνται οι τελευταίες 3 εκτελέσεις
  (ρυθμιζόμενο) και οι παλιότερες σβήνονται μόνες τους. Αν αποτύχει το backup, η ενημέρωση
  των ζυγών συνεχίζει κανονικά με προειδοποίηση στο log.
- **Μισοτελειωμένο αρχείο ERP**: πριν διαβάσει, περιμένει το μέγεθος να μείνει σταθερό σε δύο
  συνεχόμενους ελέγχους (έως 30 δευτ.), ώστε να μη σταλούν ελλιπείς τιμές στους ζυγούς.
